## Decisions
- Generated model manifests are artifacts and are ignored with the fitted models
  they describe; they must be regenerated by training in a new checkout.
- A source-only checkout must run all unit and source-contract tests without
  requiring restricted OASIS data or generated results.
- Artifact contracts remain part of the default suite. They are skipped only
  when none of the relevant local artifacts exists, then activate automatically
  after reproduction begins.
- Partially present artifact groups are treated as errors rather than skipped.
- `.vscode/`, caches, operating-system metadata, raw and derived data, models,
  outputs, and rendered reports remain local.
- The initial commit uses an explicit allowlist rather than staging the entire
  workspace.

## Unresolved issues
- Reproducing artifact-contract tests requires authorized local OASIS-2 data and
  execution of the documented pipeline phases.
- The held-out partition contains only 30 subjects and has already been
  inspected across both training conditions.
- No independent external cohort has validated the reported differences.
- Synthetic data provide no formal privacy guarantee and may reproduce source
  biases.
- This remains contemporaneous classification, not early detection, prognosis,
  clinical validation, or a deployable diagnostic system.
- Joblib artifacts must come from a trusted source and use manifest-compatible
  library versions; macOS also requires an external OpenMP runtime for XGBoost.
- No source-code license has been selected, and no remote repository is
  configured.
- SHAP and SDV emit four upstream deprecation/metadata warnings during tests;
  they do not cause failures.
